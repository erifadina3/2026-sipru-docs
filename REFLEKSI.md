# Refleksi Pengembangan

Selama proses pengembangan SIPRU, terdapat beberapa tantangan:

1. Integrasi frontend dan backend memerlukan sinkronisasi struktur data.
2. Pengelolaan status numerik membutuhkan konsistensi antara layer backend dan frontend.
3. Penerapan Git Flow membutuhkan kedisiplinan dalam pembuatan branch dan pull request.

Pembelajaran utama dari proyek ini adalah pentingnya arsitektur yang terstruktur serta version control yang baik untuk menjaga stabilitas sistem.

Ke depan, sistem dapat dikembangkan dengan autentikasi pengguna dan integrasi mobile client.
